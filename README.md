# GEDUC/RAE Mobile

Aplicativo Flutter para gestão das ações de educação para o trânsito.

## Módulos incluídos

- Login
- Home
- Nova ação
- Localização
- Resultados
- Evidências
- Avaliação
- Revisão
- Administração
- Dashboard
- Firebase services
- Offline service

## Instalação

```bash
flutter pub get
flutterfire configure
flutter run
```

> Observação: execute `flutterfire configure` para gerar `lib/firebase_options.dart` antes de rodar com Firebase real.
