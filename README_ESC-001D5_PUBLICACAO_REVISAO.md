# ESC-001D.5 — Publicação e Revisão

Baseline: `cf0df4c0aa510e470db209e28cc762700190a878`

Entrega:

- análise estrutural antes da publicação;
- alertas operacionais não bloqueantes;
- publicação da escala do dia;
- versão 1 inicial;
- revisão com motivo obrigatório;
- nova versão em rascunho;
- versão publicada anterior continua visível durante a revisão;
- republicação atômica da raiz;
- versão anterior arquivada;
- preparação de revisão retomável;
- classificação complementar continua exclusiva do responsável;
- Gerente pode clonar classificação existente com proveniência verificada;
- sem financeiro;
- sem execução/RAE/PDF.
